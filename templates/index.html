5-Layer Intelligent Security Architecture

Comprehensive multi-stage pipeline designed for production email security.

1. AI Spam Detection

TF-IDF n-gram feature vectorization with trained Linear SVM, Naive Bayes, and Logistic Regression models evaluated on accuracy, precision, recall, and F1-score.

2. Suspicious Content Analysis

Heuristic rule engine scanning for urgency pressure, credential/OTP theft, fake lottery winnings, and structural anomalies like shouting capitalization.

3. Suspicious URL Forensics

Non-request link analysis detecting direct IP hosts, URL shorteners, deceptive subdomains, suspicious TLDs, and path credential lures.

4. 0–100 Email Risk Score

Weighted composite scoring algorithm combining ML probability (50%), threat indicators (25%), URL forensics (15%), and formatting anomalies (10%) into Low, Medium, or High Risk.

5. Explainable AI Dashboard

Transparent decision auditing showing influential vocabulary weights, exact triggered triggers, and tailored cybersecurity remediation guidelines.
